01treat historical rows as usable context, not passive storage
02score a live case against learned patterns in structured data
03retrieve similar prior cases so the output has concrete context
04edit inputs and rerun immediately for what-if analysis
05show held-out evidence and uncertainty before trusting the live score
# in this prototype, TabFM provides the tabular scoring and a helper retrieval layer provides similar-case lookup
LIVE SCORING SIMILAR CASES WHAT-IF ANALYSIS
speaker note"This is the technical pattern I want people to remember. An LDM-style workflow does not stop at storing rows or charting aggregates. It uses historical rows as context, scores a live case, brings back similar prior cases, and lets the user test changes before acting. In this demo, TabFM handles tabular pattern recognition, the retrieval layer brings back relevant examples, and marimo turns that into an interactive workflow. The business value comes from that combination: faster triage, more grounded decisions, and less bespoke model-building before a team can test whether the workflow is useful."
